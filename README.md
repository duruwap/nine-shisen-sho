# 9천성 (Nine Link)

사천성의 '경로 연결' + 사과게임의 '숫자 합산'. **합이 9인 두 패**를 최대 2번 꺾이는 빈 경로로 이으면 팡! 120초 타임어택 퍼즐.

## 실행

```bash
pip install -r requirements.txt
python app.py          # http://localhost:15004
```

## 테스트

```bash
node --test tests/*.test.js   # 경로 판정 · 보드 생성 · 막힘 처리
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `app.py` | Flask 서버 (포트 15004), `/` 게임 · `/healthz` |
| `templates/index.html` | 시작 · 게임 · 결과 화면, 규칙/설정/일시정지 오버레이 |
| `static/js/logic.js` | DOM 없는 규칙 엔진: 최소 꺾임 BFS 경로 판정(외곽 1칸 포함), 균형 보드 생성, 막힘 검사 → 셔플(10회) → 값 스왑 보정 |
| `static/js/main.js` | 게임 루프, 점수·콤보, 입력(탭/클릭/키보드), 점선 경로·팡·셔플 연출, 결과 공유 이미지 |
| `static/js/audio.js` | Web Audio API 효과음 합성 (음원 파일 없음) |
| `static/js/i18n.js` | 한·영·중·일 |
| `static/css/style.css` | 크림 톤 라이트/다크 테마, 반응형 보드 |

## 기획서 대비 결정 사항

- **하드모드** = 합 9 · 최대 1번 꺾임 (열린 질문). `logic.js`의 `MODES`에 `{ target: 11, values: [2..9] }`를 추가하면 합 11 모드도 바로 동작합니다.
- **판 클리어** = 점수 +10만 (보너스 시간 없음, 열린 질문).
- **셔플** 중에도 시간은 흐르되 패널티 없음, 연출 0.4초.
- 새 보드(첫 판 · 클리어 후)는 이을 수 있는 쌍이 3쌍 이상일 때까지 재생성.
- 보드 외곽 1칸은 화면에서 반 칸 폭으로 그려서 360px 폭 폰에서도 패가 44px 이상 나오게 했습니다.
- 가로 화면(폭 ≥ 640px)은 8×6, 세로는 6×8. 게임 중 회전하면 보드를 전치해 이어서 진행합니다.
- 2차 범위 중 힌트(3회), 다크모드, 다국어, 결과 공유 이미지를 함께 넣었습니다. 랭킹 · 일일 챌린지는 미구현 (`makeRng(seed)`로 시드 보드는 준비됨).

## 조작

- 모바일: 탭-탭
- PC: 클릭, 방향키 + Space, `H` 힌트, `Esc` 일시정지
